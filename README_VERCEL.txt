제일유리 SEO 최종 배포본 V1
=========================

현재 기준 공식 주소
https://jeilglass.vercel.app/

GitHub/Vercel 반영 방법
1. 이 ZIP을 압축 해제합니다.
2. 폴더 안의 파일 전체를 GitHub glass-home 저장소 루트에 업로드합니다.
3. 같은 이름의 파일은 덮어씁니다.
4. 새 파일 assets/og-jeilglass.jpg, sitemap.xml, SEO_STATUS.txt도 함께 추가합니다.
5. Commit changes를 누릅니다.
6. GitHub와 연결된 Vercel이 자동 재배포합니다.
7. 배포 후 아래 주소를 확인합니다.
   - https://jeilglass.vercel.app/
   - https://jeilglass.vercel.app/sitemap.xml
   - https://jeilglass.vercel.app/robots.txt

추후 독립 도메인을 구매하면 URL 기반 SEO 항목만 새 도메인으로 다시 맞추면 됩니다.
